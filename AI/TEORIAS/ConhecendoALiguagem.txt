- Tipos de Dados

| Categoria             | Tipo Python  | Exemplo                | Teoria objetiva                                                                          |
| --------------------- | ------------ | ---------------------- | ---------------------------------------------------------------------------------------- |
| **Texto**             | `str`        | `"Olá"`                | Armazena uma sequência de caracteres, como palavras, frases e textos.                    |
| **Inteiro**           | `int`        | `10`                   | Armazena números inteiros, positivos, negativos ou zero, sem casas decimais.             |
| **Decimal**           | `float`      | `10.5`                 | Armazena números com casas decimais.                                                     |
| **Complexo**          | `complex`    | `2 + 3j`               | Representa números complexos, formados por uma parte real e uma parte imaginária.        |
| **Booleano**          | `bool`       | `True` / `False`       | Representa valores lógicos: verdadeiro ou falso.                                         |
| **Lista**             | `list`       | `[1, 2, 3]`            | Coleção ordenada e mutável de elementos. Pode conter diferentes tipos de dados.          |
| **Tupla**             | `tuple`      | `(1, 2, 3)`            | Coleção ordenada e imutável de elementos.                                                |
| **Intervalo**         | `range`      | `range(10)`            | Representa uma sequência de números, muito utilizada em repetições e loops.              |
| **Conjunto**          | `set`        | `{1, 2, 3}`            | Coleção não ordenada de elementos únicos. Não permite valores duplicados.                |
| **Conjunto imutável** | `frozenset`  | `frozenset({1, 2, 3})` | Versão imutável de um `set`, que não pode ser alterada depois de criada.                 |
| **Dicionário**        | `dict`       | `{"nome": "Jhonatan"}` | Armazena dados no formato **chave → valor**, permitindo acessar valores por suas chaves. |
| **Bytes**             | `bytes`      | `b"Olá"`               | Armazena uma sequência imutável de valores binários, representados por bytes.            |
| **Bytes mutável**     | `bytearray`  | `bytearray(b"Olá")`    | Similar a `bytes`, mas permite modificar os valores depois de criado.                    |
| **Memória**           | `memoryview` | `memoryview(b"Olá")`   | Permite acessar dados binários diretamente na memória sem precisar copiar os dados.      |
| **Nulo**              | `NoneType`   | `None`                 | Representa a ausência de um valor ou a inexistência de um resultado.                     |
